## ✨ Features & Architecture

- **Dark Theme & Glassmorphism**: Deep navy background (`#0B1120`), glowing indigo/cyan neon accents, and frosted glass cards.
- **Interactive Particle Constellation**: Hardware-accelerated canvas particle system reacting to mouse proximity (with full `prefers-reduced-motion` accessibility support).
- **Interactive Developer Workspace**:
  - Live code tabs: `Main.java`, `theft_detection.py`, `schema.sql`, `App.tsx`
  - Integrated terminal simulation with real output execution
  - 3D mouse parallax tilt effect
- **Featured Project Showcase — AI Theft Detection System**:
  - Python + YOLO + OpenCV + Flask + SQLite + Telegram Bot API
  - Interactive 5-stage visualizer:
    $$\text{Camera Stream} \longrightarrow \text{AI Detection} \longrightarrow \text{Behavior Analysis} \longrightarrow \text{Instant Alert} \longrightarrow \text{Event Ledger}$$
- **Milestone Timeline**: Clear, honest distinction between Academic Degree, Dual Internships (AI & Full Stack), and Professional Java Training.
- **In-Browser Resume Viewer**: Full-screen printable CV modal + safe download fallback (`/resume.pdf`).
- **Accessible Contact Dispatch**: Form validation for Name, Email, Subject, and Message with direct mail client integration.
- **SEO Optimized**: Dynamic `robots.txt`, `sitemap.xml`, OpenGraph cards, Twitter cards, and Schema.org JSON-LD Person metadata.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or later)
- npm or yarn or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aathidasan/Portfoliowebsite.git
   cd Portfoliowebsite
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm start
```
